# horizon-impacted
Неофициальный проект на основе Horizon для Minecraft 26.3 с меню в стиле Impact. XRay с фильтрами, подсветка и линии к врагам, упреждение лука для игроков, список своих с защитой от ударов, автокриты и строительство мостов из блоков. Офлайн-запуск без Microsoft; ресурсы Minecraft нужны отдельно. Проект в разработке, не является оригинальным Impact.
